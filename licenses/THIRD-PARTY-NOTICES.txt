This application uses Python, PyInstaller, PySide6/Qt and Shiboken.
The Windows build copies the installed distributions' notices and package
metadata into dist/licenses, together with Python's own license.

Pinned Qt for Python packages: 6.10.3, obtained from their official PyPI wheels.
Their package metadata declares LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only.
The license texts included here accompany the notices shipped in the wheels.
Qt source: https://code.qt.io/cgit/pyside/pyside-setup.git/tag/?h=v6.10.3
Qt base source: https://code.qt.io/cgit/qt/qtbase.git/tag/?h=v6.10.3

The bundled Microsoft runtime binaries are the unmodified redistributable
files supplied in the pinned Windows Shiboken wheel. They are distinct from
the user's separately supplied firmware tools.
Microsoft deployment documentation:
https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files

The application source and build scripts are supplied with this project.
No external firmware tool binary is included in the public release ZIP.
