# Tool download disclosures

The confirmation displays filenames and download URLs from the same ToolSpec objects used by the downloader. It starts no worker until the user selects Yes. No, Escape and closing the dialog cancel. Intel FPT uses one confirmation for its three files. Labels and explanatory text are supplied in both bundled languages; original copyright notices are retained.
