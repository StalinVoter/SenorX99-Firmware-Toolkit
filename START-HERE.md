# SenorX99 v0.93

Extract the whole ZIP, then open **SenorX99.exe**. You do not need to install Python. Keep all extracted folders beside the executable.

Click the Union Jack or Brazilian flag above any page heading to switch the whole interface immediately between English and Brazilian Portuguese. The app remembers your choice; the loaded ROM and selected modifications stay in place.

Follow the numbered steps on the left:

1. Download missing tools and continue when the files are ready.
2. Load an existing BIOS file or dump this computer's BIOS.
3. Review the analysis and continue.
4. Use the CPU-based recommendations, or choose Custom settings. Question marks explain each change.
5. Build and verify the new BIOS file.
6. Save it for later or explicitly choose to flash this computer.

Recommended mode locks all modification controls, including the undervolt profile and logo choices. Custom settings lets you prepare a BIOS for a different computer or CPU.

If FPT cannot access the hardware, loading, modifying, building and saving an existing ROM remain available. Dumping and flashing remain unavailable until the FPT problem is resolved.

The original ROM is kept unchanged. Flashing requires an explicit confirmation and two matching backups before writing. Do not restart, remove power or close the app while flashing or recovery is running.

The source and Windows release ZIPs are available from the project’s GitHub Releases page.
